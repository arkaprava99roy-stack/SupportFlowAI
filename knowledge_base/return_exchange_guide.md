# SupportFlow Return & Exchange Step-by-Step Guide

## 1. How to Initiate a Return or Exchange
1. Log in to your SupportFlow account and visit **Orders > Return or Exchange Items**.
2. Select the specific item(s) you wish to return and indicate the primary reason (e.g., wrong size, color mismatch, item defective, changed mind).
3. Choose your preferred resolution:
   - **Direct Exchange**: Swap for a different size or color of the same product (no restocking fees).
   - **Store Credit**: Receive instant digital store credit plus an additional 5% bonus credit.
   - **Original Payment Refund**: Refund to your credit card or PayPal within standard processing windows.

## 2. Printing Return Shipping Labels
- Once your return request is submitted, a prepaid return shipping label (USPS / UPS) will be generated for download and emailed to you.
- Securely pack the items in their original box or equivalent protective packaging, affix the return label, and drop off the package at any authorized carrier drop-off depot.

## 3. Exchange Fulfillment Timeline
- For exchanges, your replacement item is reserved immediately and dispatched as soon as the return carrier registers the initial package drop-off scan.
- You will receive a new tracking number for your replacement item via email.
